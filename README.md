# introducao-filosofia-notebooklm
Este repositório reúne um guia introdutório de Filosofia criado com o apoio do NotebookLM. O projeto apresenta conceitos fundamentais e o pensamento de filósofos como Sócrates, Platão, Aristóteles, Karl Marx e Marilena Chauí, demonstrando como a Inteligência Artificial pode auxiliar na organização e no aprofundamento dos estudos.
